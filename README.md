# Maroon Mole

Maroon Mole is a modern web application built using Next.js and TypeScript.  
The project is designed with a clean structure and scalable architecture, making it suitable for future expansion into a production-ready platform.

## Overview

This application focuses on delivering a fast and organized web experience while keeping the codebase maintainable and easy to extend.

## Features

- Clean and scalable Next.js project structure
- TypeScript integration for better maintainability
- SQL database integration (database.sql included)
- Organized source code inside the src directory
- Optimized build and deployment-ready configuration

## Technologies Used

- Next.js
- React
- TypeScript
- Node.js
- SQL
- PostCSS
